# 🚀 TaskFlow – Project Management Tool

A full-stack collaborative project management platform inspired by **Trello and Asana**, designed to help teams organize projects, manage tasks, assign responsibilities, and communicate efficiently.

## 📌 Project Overview

TaskFlow is a web-based project management application that allows users to create group projects, manage project boards, assign tasks to team members, and collaborate through task comments.

The platform provides a centralized workspace where teams can plan, track, and complete their projects efficiently.

## ✨ Key Features

- 🔐 **User Authentication** – Secure user registration and login.
- 👥 **Group Projects** – Create and manage collaborative projects.
- 📋 **Project Boards** – Organize projects using visual task boards.
- 📝 **Task Management** – Create, edit, delete, and manage tasks.
- 👤 **Task Assignment** – Assign tasks to specific team members.
- 💬 **Comments & Communication** – Discuss tasks through comments.
- 🔄 **Task Status Tracking** – Track tasks using To Do, In Progress, and Completed.
- 📅 **Deadline Management** – Set and track task deadlines.
- 📱 **Responsive Design** – Access the platform on desktop, tablet, and mobile devices.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mrunalllll/DASH-BOARD.git
```

### 2. Navigate to the Project

```bash
cd DASH-BOARD
```

### 3. Install Dependencies

Install frontend and backend dependencies separately:

```bash
cd frontend
npm install
```

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 5. Run the Application

Start the backend:

```bash
npm run dev
```

Start the frontend in another terminal:

```bash
cd frontend
npm run dev
```
